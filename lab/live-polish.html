Live Polish

A visual style editor that lives in your page.

After turning on Live Polish, click any element in this site. Tweak its size, colour, font, spacing, shadow, radius. When you're happy, export a clean CSS diff or even copy a changes as a prompt for those of you who work with AI.

  1. Press Ctrl+Shift+P to turn the editor on.
  2. Click any element — the headline, a button, a card.
  3. Use the side panel to tweak. Watch it change live.
  4. Hit Copy CSS or Copy Prompt in the panel when you're done.
Edits save in your browser.
